# 网页界面设计

## 产品目标

管理台面向单个 ME 网络管理员。界面的首要任务是快速判断网络是否健康，其次是读取库存，最后才是执行会改变游戏状态的操作。视觉层级必须保持这个顺序。

## 设计语言

界面使用“ME 网络控制柜”语言，而不是通用 SaaS 卡片：侧栏代表机柜，连接状态沿 ME 总线显示，总览以核心节点、链路和外围模块表达真实网络关系。

- 背景 `#070b10`，机柜 `#0d151e`，模块 `#111e2a`。
- AE 信号使用 `#69e7ff`，存储单元使用 `#9c8cff`。
- 成功使用 `#63e6a7`，警告和受控写操作使用 `#ffc857`，故障使用 `#ff7a87`。
- 标题优先使用 Bahnschrift，正文使用系统 UI 字体，数值、ID 和注册名使用 Cascadia Mono 或等宽回退字体。

颜色不单独承担状态表达：在线、离线、成功和失败始终同时提供文字标签。

## 页面结构

- 总览：连接健康、ME 拓扑、能量、耗能、合成 CPU、外围设备和代理信息。
- 库存：选择物品、流体或气体后按需读取，每页最多 200 项；显示当前范围、总数和快照时间，不持续轮询大型列表。分页按钮保持原生键盘操作和至少 44px 点击区域，搜索范围明确限定为当前页。
- 操作：以独立的警告色安全区呈现，保留限额、设备授权和二次确认。
- 设备：先展示发现结果，再配置收藏、写权限、方向和资源限额。
- 审计：用表格化列表追踪结果、对象、执行者、时间和数量。
- 设置：只配置全局安全限额，设备级覆盖仍在设备页完成。

导航状态写入 URL hash，例如 `#inventory`，允许刷新、返回和直接打开具体页面。

## 响应式与可访问性

- 桌面使用固定机柜侧栏；小于 820 px 时改为顶部可横向滚动的导航。
- 1120 px 以下总览指标改为两列，560 px 以下改为单列。
- 所有交互目标最小高度为 44 px，并提供可见的键盘焦点环。
- 页面提供跳到主要内容链接；SVG 图标为装饰元素，不重复朗读可见文字。
- 减少动画偏好会关闭非必要过渡和页面进入动画。
- 库存列表使用 `content-visibility` 降低大型快照的渲染成本。

## 安全边界

视觉改版不改变 Worker、Durable Object、D1 或 Lua Agent 协议。写操作仍必须经过准备、一次性确认令牌、队列执行和审计记录；按钮在请求期间禁用，以避免重复提交。
